Protocol

如何使用

演示页为只读模式，不连接后端，不会修改任何项目或记忆数据。

  1. 01

    从 v5 开发源码构建并配置主 MCP；需要 Node.js 22+ 和一个 Git 项目。

  2. 02

    调用 devcontrol 的 SQLite 只读动作（list / features / work-items / idea-list）。

  3. 03

    Host 协商 UI 扩展后展示新的项目工作台；没有 UI 支持的客户端仍使用结构化 MCP 结果。
