MCP Apps 可视化工作台

五个原生 App 把计划、记忆、产品交付和证据闸门带进支持 MCP Apps 的客户端。

如何使用

演示页为只读模式，不连接后端，不会修改任何项目或记忆数据。

  1. 01

    在支持 io.modelcontextprotocol/ui 的客户端中配置 mcp-probe-kit@next。

  2. 02

    正常调用 start_feature、start_bugfix、start_product、converge 或 Memory 工具。

  3. 03

    Host 协商成功后自动打开对应工作台；不支持 Apps 的客户端仍收到文本和 structuredContent。

start_feature

Feature Workbench

计划步骤、当前任务、产出、证据和恢复状态。

ui://mcp-probe-kit/feature-workbench

start_bugfix

Bug Workbench

沿 SRC-8 真因流程展示边界、阻断、验证和回归。

ui://mcp-probe-kit/bug-workbench

search_memory · list_memory_assets

Memory Center

语义检索、全文查看、生命周期、证据、过期标记和确认删除。

ui://mcp-probe-kit/memory-center

start_product

Product Workbench

从产品定义、PRD、原型和设计系统交接到 start_feature。

ui://mcp-probe-kit/product-workbench

converge

Convergence Gate

严格检查需求、规格、实现、测试和审查证据，决定是否允许交付与记忆写入。

ui://mcp-probe-kit/convergence

兼容与降级

MCP Apps 不是使用前提。未协商 UI 扩展时，工具数量和原有文本工作流保持不变；App-only 动作不会暴露给模型。
