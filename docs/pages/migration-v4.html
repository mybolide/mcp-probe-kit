MCP Probe Kit v3 → v4

v4 保留现有工具与 delegated workflow，升级重点是 SDK v2 双协议、可恢复计划、收敛闸门和更可靠的记忆治理。

33 tools Node.js 20+ Legacy + Modern

升级前

  1. 升级到 Node.js 20 或更高版本。
  2. 记录当前 v3 包版本和 MCP 客户端配置。
  3. 确认项目 Spec、上下文文档和 Memory 配置可读取。

RC 安装

候选版本使用 npm next 标签，不覆盖稳定版 latest。

npx -y mcp-probe-kit@next

# 全局安装
npm install -g mcp-probe-kit@next

# 固定版本
npm install -g mcp-probe-kit@4.0.0-rc.1

完成真实客户端验收并发布稳定版后，再切换到 mcp-probe-kit@4 或 latest。

协议模式

模式行为
auto默认；自动识别 Legacy 或 Modern 客户端。
legacy客户端不兼容新 opening 时排障。
modern仅用于 Modern 协议和扩展验证。
 
MCP_PROTOCOL_MODE=auto

计划状态与恢复

start_*
→ plan_heartbeat
→ 执行与验证
→ resume_plan（仅中断后）
→ converge
→ memorize_asset（仅收敛通过后）

检查点保存在项目本地 .mcp-probe-kit/plans/，不会代替 Agent 修改代码。

兼容与降级

  • Legacy Tasks 保持可用。
  • Modern Tasks 尚未默认宣告支持，自动同步降级。
  • input_required 仅在客户端声明能力时启用。
  • Apps、Progress 或 Resources 不可用时，核心工具继续运行。

验证与回退

npm run eval:agents
npm run release:verify

客户端异常时优先设置 MCP_PROTOCOL_MODE=legacy。只有 SDK v2 存在无法规避的严重回归时，再回退固定的 v3 包版本。

完整技术说明见仓库中的 docs/migration-v3-to-v4.md。历史 v2 → v3 指南仍可在 此处 查阅。
